# Junior — 01 Language Basics: Topics to Master

Questions in this level come from the subtopics below (in learning-path order).

| # | Subtopic | What it covers |
|---|----------|----------------|
| 01 | Variables and Constants | `var`, `const`, `:=`, zero values, shadowing, typed vs untyped constants, `iota` |
| 02 | Data Types | int/float/bool/rune/byte, type conversions, numeric limits, overflow |
| 03 | Composite Types | slices, arrays, maps, structs — creation, aliasing, backing arrays |
| 04 | Conditionals | `if`/`else`, `switch`, `if`-init statements, short-circuit eval |
| 05 | Loops | `for` forms, `range`, `break`/`continue`, labels, loop-var capture |
| 06 | Functions | params/returns, multiple returns, variadic, closures, `defer`, named returns |
| 07 | Pointers | `&`/`*`, pass-by-value vs pointer, nil pointers, pointer receivers |
| 08 | Arrays | fixed-size arrays, value semantics, array vs slice difference |
| 09 | Strings | UTF-8, runes vs bytes, indexing, iteration, `strings` package basics |
| 10 | Maps | declaration, comma-ok, deletion, iteration order, nil maps |
| 11 | Structs | fields, methods, embedding, tags, comparison, zero-value structs |
| 12 | Bit operations
